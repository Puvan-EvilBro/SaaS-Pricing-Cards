
# SaaS Product Pricing Cards

## Project Description
A modern and responsive SaaS pricing page built using HTML, CSS, and JavaScript. It allows users to switch between monthly and yearly billing plans with interactive pricing cards.

## Features
- Responsive design for desktop, tablet, and mobile.
- Monthly and Yearly billing toggle.
- Dynamic price updates using JavaScript.
- Popular and Best Value ribbon badges.
- CSS hover effects and smooth transitions.
- Three pricing plans: Starter, Professional, and Enterprise.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
4. Switch between Monthly and Yearly billing.
5. Hover over the pricing cards to view animations.
